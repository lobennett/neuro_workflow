# docs/archive

Historical planning, spec, and reference artifacts, kept for the audit trail. **These are
not authoritative** — for current documentation see `docs/WORKFLOW.md`,
`docs/ARCHITECTURE.md`, and `docs/RUNBOOK.md` (plus `docs/EXCLUSIONS.md`,
`docs/EXCLUSIONS-FLOW.md`, `docs/PROVENANCE.md`, `docs/CONFIG.md`).

Contents:

- `superpowers/` — dated `plans/` and `specs/` process artifacts from the brainstorm →
  design → plan → execute workflow (39 files). Snapshot of how features were scoped at the
  time; superseded by the merged code and the authoritative docs above.
- `REFACTOR-PLAN.md` — the simplification/provenance refactor plan; the work it describes
  has since been executed and merged.
- `RSE-PRINCIPLES.md` — research-software-engineering reference notes used to guide the
  refactor; background reading, not a spec for current behavior.
- `PIPELINE.md` — a 2026-05-31 "draft navigational spine" auto-generated by a codebase
  audit (self-labeled draft, never listed as authoritative in CLAUDE.md). It duplicated the
  end-to-end journey and exclusion logic already owned authoritatively by `WORKFLOW.md`,
  `ARCHITECTURE.md`, `EXCLUSIONS.md`, and `EXCLUSIONS-FLOW.md`, and still carried unresolved
  `[VERIFY]` markers, so it was archived rather than maintained as a parallel source.
